# Customer Shopping Behavior Analysis

## Overview

This project focuses on analyzing customer shopping behavior using **Python, SQL, and Power BI**. The analysis transforms raw retail transaction data into structured insights related to customer preferences, purchasing patterns, product performance, and customer segmentation.

The project follows an end-to-end data analytics workflow, covering data preparation, exploratory analysis, SQL-based business analysis, and interactive data visualization.

## Technology Stack

* **Python** – Data cleaning and exploratory data analysis
* **Pandas & NumPy** – Data manipulation and analysis
* **SQL** – Data querying and business analysis
* **Power BI** – Dashboard development and visualization
* **Google Collab** – Analytical workflow and documentation

## Project Workflow

```text
Raw Data
   ↓
Data Cleaning & Preparation
   ↓
Exploratory Data Analysis
   ↓
SQL Analysis
   ↓
Business Insights
   ↓
Power BI Dashboard
```

## Key Areas of Analysis

* Customer purchasing behavior and spending patterns
* Customer segmentation and demographic analysis
* Product and category performance
* Purchase frequency and customer loyalty
* Sales and revenue trends
* Identification of high-value customer segments
* Business-focused KPI analysis

## Objectives

The primary objectives of the project are to:

* Analyze customer purchasing patterns and preferences
* Identify significant trends within retail transaction data
* Evaluate product and category performance
* Segment customers based on purchasing behavior
* Develop meaningful KPIs for business analysis
* Translate analytical findings into actionable business insights
* Present insights through an interactive Power BI dashboard

The project demonstrates the application of **data cleaning, exploratory data analysis, SQL querying, customer segmentation, KPI development, and business intelligence visualization** to derive meaningful insights from retail data.
